# personal-page

Página pessoal com uma breve apresentação, CV para descarregar e ligações para o LinkedIn e GitHub.

Pensada para partilhar através de um QR code, incluindo na feira de empresas do ISEP, e consultar em telemóvel ou PC.

## Estado atual

O repositório contém a documentação e as referências visuais. O site ainda não está implementado nem publicado.

## Organização

- `doc/README.md`: conteúdo previsto e orientações para a página.
- `doc/design/desktop.svg`: referência visual para PC.
- `doc/design/mobile.svg`: referência visual para telemóvel.

## Design

[Proposta editável no Figma](https://www.figma.com/design/xdso1MuNYcD5hdSc1gt7is)

Os SVG representam a proposta visual. A implementação deve aplicar o ajuste posterior: conteúdo centrado horizontal e verticalmente na área visível, com deslocação quando necessário.

## Publicação prevista

GitHub Pages, a partir deste repositório. O endereço e as instruções de execução serão adicionados quando o site estiver implementado e a publicação confirmada.
